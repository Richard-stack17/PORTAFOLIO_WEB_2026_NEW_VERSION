# Portfolio - Richard Alfaro Manzano

Personal portfolio showcasing my expertise as a Full-Stack Developer and Systems Engineer. Built with modern web technologies focusing on performance, accessibility, and clean architecture.

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Library:** React 19
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Internationalization:** next-intl (English / Spanish)
- **Animations:** AOS (Animate On Scroll)
- **Forms:** Formspree API

## Features

- Fully responsive and mobile-first architecture.
- Dark mode Neo-Dark UI / Glassmorphism aesthetic.
- Built-in i18n support for English and Spanish.
- Smooth scrolling and scroll-triggered animations.
- Serverless contact form integration.

## Getting Started

### Prerequisites

- Node.js 18.x or later

### Installation

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   ```

2. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser.
